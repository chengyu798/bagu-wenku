## 这份精读是什么

《深度学习》（Deep Learning，Goodfellow、Bengio、Courville）常被称为「花书」。它不是一本入门教程，而是一本把深度学习放进线性代数、概率论和机器学习框架里系统讲清楚的书。

这里按原书章节结构整理**原创学习笔记**。每章不是提纲，而是从问题出发的完整讲解：先交代背景和动机，再展开核心概念、公式、推导直觉和例子，最后用小结收束。**不复制原文、图表和例子**；原书 PDF 只保留在本地 `books/deep-learning/`，不随网站发布。

## 怎么读

- **第一遍读主干**：第 1、5、6、7、8、9、10 章，先建立「机器学习基础 → 前馈网络 → 训练 → 卷积/序列」的主线。
- **第二遍补数学**：第 2–4 章按需回查，不必一次啃完；读到公式再回来查定义。
- **第三遍读研究**：第 13–20 章偏生成模型和概率推断，按兴趣选读，先看第 13、14、19、20 章。
- **每章慢慢读**：每章按 15–30 分钟安排，先把讲解和例子读懂，再用最后的小结和复习清单自测；不要只扫标题。

## 关于时代

花书出版于 2016 年，主线还是前馈网络、CNN 和 RNN。书中没有 Transformer、扩散模型和大规模预训练，这些内容在今天的实践中已经非常关键。笔记会在相关章节标注「今天怎么看」，帮助你区分**仍然成立的基础**和**已经被后续工作改写的方法**。

## 学习建议

1. **不要逐字读**：先看每章的「本章解决什么问题」和「核心脉络」，再决定哪些小节值得展开。
2. **公式要落到直觉**：每个公式至少能说清「它在约束什么」「梯度往哪走」「和损失函数什么关系」。
3. **和面试卡片配合**：花书打原理底子，Agent、深度学习分类里的卡片用来练面试表达。
4. **用自己的例子复述**：能用一个和自己项目相关的例子讲清楚，才算真正掌握。
