## 序列数据难在哪

图像有固定大小，序列没有。一句话可以是 5 个词，也可以是 500 个词；语音的长度随时间变化；股票价格、传感器读数、用户行为都是时间序列。更麻烦的是，序列中的元素不是独立的：当前词的含义依赖前文，当前状态依赖历史。

全连接网络要求固定输入大小，也无法共享「相邻时间步之间的规律」。循环神经网络（RNN）用同一个函数在每个时间步复用，并用一个隐藏状态把历史信息传下去。

## 循环网络的基本形式

RNN 在每个时间步做：

```text
h_t = tanh(W_h h_{t-1} + W_x x_t + b)
y_t = W_y h_t + c
```

`h_t` 是隐藏状态，既包含当前输入 `x_t` 的信息，也包含上一时刻 `h_{t-1}` 的信息。同一个 `W_h`、`W_x` 在所有时间步共享，所以模型能处理任意长度的序列，参数量也不随序列长度增长。

如果把 RNN 按时间展开，它看起来像一个很深的共享参数的前馈网络。训练时用通过时间反向传播（BPTT）：先前向算每个时刻的输出和损失，再从最后一步往回传梯度。

## 梯度消失与梯度爆炸

BPTT 的梯度要沿时间连乘很多次。如果每一步的雅可比矩阵的谱半径小于 1，梯度会指数级衰减；大于 1，会指数级爆炸。

梯度消失的后果是：模型很难学到长距离依赖。比如一句话开头的主语，到句尾才决定动词的单复数；如果中间隔了几十个词，普通 RNN 的梯度已经传不回去了。

梯度爆炸相对好处理：梯度裁剪把范数限制在一个阈值内。梯度消失更难，需要结构上的改进。

## LSTM 与门控

长短期记忆网络（LSTM）引入一个单元状态 `c_t` 和三个门：

- **遗忘门**：决定保留多少旧记忆；
- **输入门**：决定写入多少新信息；
- **输出门**：决定当前输出多少记忆。

```text
f_t = σ(W_f [h_{t-1}, x_t] + b_f)
i_t = σ(W_i [h_{t-1}, x_t] + b_i)
o_t = σ(W_o [h_{t-1}, x_t] + b_o)
c_t = f_t ⊙ c_{t-1} + i_t ⊙ tanh(W_c [h_{t-1}, x_t] + b_c)
h_t = o_t ⊙ tanh(c_t)
```

关键在 `c_t` 的更新是**加法**而不是连乘。梯度可以沿着单元状态更直接地流动，缓解了梯度消失。门控是 0 到 1 之间的软开关，由数据学习，而不是人写死。

GRU 是 LSTM 的简化版，用更新门和重置门，参数更少，很多任务上效果接近。选择 LSTM 还是 GRU，通常看数据和任务，没有绝对优劣。

## 双向与深层 RNN

单向 RNN 只能看到过去。对很多任务（比如给一个句子做分类），未来的上下文同样重要。双向 RNN 用两个方向的 RNN 分别处理序列，再把表示拼接起来。

深层 RNN 堆叠多层，让表示逐层抽象。但深层 RNN 训练更难，需要残差连接、LayerNorm 或门控结构。

## 编码器—解码器与 seq2seq

机器翻译、摘要、对话都是「输入一个序列，输出另一个序列」。seq2seq 用编码器把输入序列压成一个表示，再用解码器逐步生成输出。

编码器最后的状态要承载整个输入的信息，这形成了一个瓶颈：输入越长，信息越难压缩到一个固定向量里。解码器在生成每个词时，只能看这个固定向量，容易丢失细节。

## 注意力机制

注意力让解码器在每一步动态地看输入的不同位置。它计算一个权重分布：

```text
α_ti = softmax(score(h_t, s_i))
context_t = Σ α_ti s_i
```

`h_t` 是解码器当前状态，`s_i` 是编码器第 `i` 个位置的状态。权重表示「当前生成这个词，应该关注输入的哪些部分」。

注意力解决了 seq2seq 的瓶颈：解码器不必把所有信息压进一个向量，而是可以按需检索。它也让模型的行为更可解释，因为可以看到对齐关系。注意力后来成为 Transformer 的核心，虽然 Transformer 不再使用循环结构。

## 序列建模的实践

- 文本通常先分词或切成子词，再映射成嵌入。
- 训练语言模型时，用前面的词预测下一个词，损失是交叉熵。
- 梯度裁剪对 RNN 很重要。
- 变长序列要 padding 和 mask，避免把填充位置算进损失。
- 推理时可以用贪心、beam search 或采样。

## 小结

- RNN 用共享参数和隐藏状态处理变长序列。
- BPTT 沿时间反向传播，长序列容易出现梯度消失或爆炸。
- LSTM/GRU 用门控和加法记忆缓解长距离依赖。
- seq2seq 解决序列到序列的任务，但固定向量形成瓶颈。
- 注意力让解码器动态关注输入，是后来 Transformer 的直接前身。
