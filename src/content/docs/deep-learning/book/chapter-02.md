## 为什么神经网络离不开线性代数

神经网络的一层，本质上就是一次线性变换加一次非线性激活：`h = σ(Wx + b)`。这里的 `W` 是矩阵，`x` 是向量，`b` 是偏置。一次前向传播会做大量矩阵乘法，一次反向传播又要用矩阵转置和雅可比矩阵。如果不理解矩阵运算的几何意义，看模型结构时很容易只记住符号，却不知道它在做什么。

这一章的目标不是把所有线性代数定理背下来，而是建立几个能反复使用的直觉：矩阵是变换，范数是度量，特征分解和 SVD 是拆解变换的工具，PCA 是用这些工具做降维。

## 向量与矩阵：两种视角

向量可以看作一个带方向和大小的箭头，也可以看作一组数。矩阵可以看作一张数表，也可以看作一个函数：它把输入向量映射成另一个向量。

第二种视角更重要。比如矩阵

```text
A = [[2, 0],
     [0, 1]]
```

作用在向量 `(x, y)` 上，会把它变成 `(2x, y)`：横向拉伸两倍，纵向不变。矩阵乘法 `Ax` 不是一堆数字的机械组合，而是在对空间做旋转、拉伸、剪切或投影。

矩阵乘法还有一层含义：`C = AB` 表示先做 `B` 的变换，再做 `A` 的变换。因为矩阵乘法不满足交换律，所以顺序很重要。神经网络里层的顺序、残差连接的位置，都会改变最终的变换。

## 范数：怎么衡量「大」

范数给向量一个非负的长度。最常用的是 L2 范数：

```text
||x||₂ = sqrt(x₁² + x₂² + ... + xₙ²)
```

它就是欧氏距离。L1 范数是绝对值之和：

```text
||x||₁ = |x₁| + |x₂| + ... + |xₙ|
```

两者在机器学习里的区别很关键。L2 正则（权重衰减）倾向于让所有权重都变小但不为零；L1 正则倾向于让一部分权重正好变成零，因此有稀疏和特征选择的效果。几何上，L1 的「单位球」是菱形，L2 的是圆形；损失等高线最先碰到菱形尖角，所以解容易落在坐标轴上。

## 特征分解：找到不变的方向

对方阵 `A`，如果存在非零向量 `v` 和标量 `λ`，使得

```text
A v = λ v
```

那么 `v` 是 `A` 的特征向量，`λ` 是对应的特征值。它的几何意义是：在 `v` 这个方向上，矩阵只做拉伸或压缩，不改变方向。特征值就是拉伸倍数。

如果一个矩阵有足够多的线性无关特征向量，就可以分解成：

```text
A = V diag(λ) V⁻¹
```

这让我们可以把矩阵变换理解成「换到特征基 → 沿坐标轴缩放 → 换回来」。在特征基下，复杂的矩阵乘法变成简单的逐元素乘法。

不是所有矩阵都能这样分解。对称矩阵有很好的性质：特征值都是实数，特征向量可以选成正交的。协方差矩阵就是对称的，这也是 PCA 能用特征分解的原因。

## SVD：任意矩阵都能拆

特征分解只适用于方阵，而且要求可对角化。奇异值分解（SVD）没有这些限制：任意 `m×n` 矩阵都可以写成

```text
A = U Σ Vᵀ
```

其中 `U` 和 `V` 是正交矩阵，`Σ` 是对角矩阵，对角线上的元素叫奇异值。几何上，SVD 表示：先旋转，再沿坐标轴缩放，再旋转。它把任意线性变换拆成了三个简单的动作。

SVD 的用途很广：降维、压缩、求伪逆、分析矩阵的有效秩。奇异值下降得越快，说明矩阵越接近低秩，越容易被低维结构近似。PCA 可以看作对中心化后的数据矩阵做 SVD，保留最大的几个奇异值对应的方向。

## 伪逆与最小二乘

对于方阵且可逆的 `A`，解 `Ax = b` 就是 `x = A⁻¹b`。但很多实际问题里 `A` 不是方阵，或者不可逆，这时可以用伪逆 `A⁺` 给出最小二乘意义下的解。

最小二乘要最小化 `||Ax - b||²`。它的解满足正规方程 `AᵀAx = Aᵀb`。如果 `AᵀA` 可逆，解就是 `(AᵀA)⁻¹Aᵀb`；更一般地，用 SVD 可以稳定地计算伪逆。深度学习里很少直接解正规方程，但理解最小二乘有助于理解损失函数和梯度。

## PCA：用方差最大的方向降维

假设我们有一堆二维点，分布像一个斜着的椭圆。PCA 想做的是：找一个方向，把点投影上去之后方差最大；再找和它正交的第二个方向。前几个方向保留了大部分变化，后面的方向可能只是噪声。

具体步骤是：

1. 把数据中心化，减去均值。
2. 计算协方差矩阵。
3. 对协方差矩阵做特征分解。
4. 取最大的几个特征值对应的特征向量作为主成分。
5. 把数据投影到这些方向上。

PCA 的意义不只是降维。它还在做去相关：在新的坐标系里，不同维度之间线性无关。它也有局限：只能捕捉线性结构，对非线性流形无能为力。这也是后面自编码器出现的动机之一。

## 小结

- 矩阵是线性变换，矩阵乘法是变换的复合。
- 范数衡量大小；L1 和 L2 会带来不同的正则化效果。
- 特征分解找到变换中方向不变的方向，SVD 把所有矩阵拆成旋转—缩放—旋转。
- PCA 用方差最大的方向降维，是 SVD 的经典应用。
- 这些工具会在前馈网络、卷积网络和生成模型里反复出现。
