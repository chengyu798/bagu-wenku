## 纸上的数学和机器里的数学

在纸上，`exp(1000)` 是一个确定的数；在计算机里，它可能直接变成 `inf`。在纸上，`0.1 + 0.2 = 0.3`；在浮点数里，它可能等于 `0.30000000000000004`。深度学习每天要做的矩阵乘法、指数、对数、求逆，都会受有限精度影响。这一章讲的就是：怎样判断一个问题在数值上「好不好算」，以及怎样让计算保持稳定。

## 上溢、下溢与 softmax

浮点数有范围。太大的数会变成无穷（上溢），太小的正数会变成 0（下溢）。这两种情况都会让后续计算失效。

最典型的例子是 softmax。给定 logits `z`，softmax 是：

```text
softmax(zᵢ) = exp(zᵢ) / Σⱼ exp(zⱼ)
```

如果某个 `zᵢ` 是 1000，`exp(1000)` 就上溢了，整个式子变成 `inf/inf`。解决办法是先减去最大值：

```text
softmax(zᵢ) = exp(zᵢ - max(z)) / Σⱼ exp(zⱼ - max(z))
```

数学上结果完全一样，但最大的指数变成 0，其他项都是负数，不会上溢。这个技巧叫 log-sum-exp，是深度学习实现里最常见的数值稳定手段之一。

下溢也很常见。比如计算很多概率的乘积，`0.01 × 0.01 × ...` 很快就会变成 0。解决办法是取对数，把乘积变成求和：`log p₁ + log p₂ + ...`。这就是为什么训练时几乎总是用对数似然，而不是直接算似然。

## 条件数：输入的一点扰动会被放大多少

有些问题对输入非常敏感。输入稍微变一点，输出就剧烈变化。这种问题叫病态（ill-conditioned）。

对方程 `Ax = b`，条件数定义为最大奇异值和最小奇异值之比：

```text
κ(A) = σ_max / σ_min
```

条件数接近 1，问题比较稳定；条件数很大，解对 `b` 或 `A` 的微小扰动非常敏感。直观上，如果矩阵在某些方向上几乎把空间压扁了，反过来的放大倍数就会非常大。

深度学习的损失曲面也有类似问题。不同方向的曲率差异很大时，梯度下降会在陡峭方向震荡、在平坦方向走得很慢。这也是为什么优化器要做归一化、动量和自适应学习率。

## 梯度、Jacobian 与 Hessian

梯度是多元函数对所有变量的一阶偏导组成的向量：

```text
∇f(x) = [∂f/∂x₁, ∂f/∂x₂, ..., ∂f/∂xₙ]
```

它指向函数增长最快的方向，所以沿负梯度方向走可以下降。梯度只给方向，不给步长；步长由学习率或线搜索决定。

Jacobian 是向量值函数的一阶偏导矩阵。如果 `f: Rⁿ → Rᵐ`，Jacobian 是 `m×n` 矩阵，描述每个输出对每个输入的敏感度。反向传播本质上是在高效地计算向量与 Jacobian 的乘积，而不是显式构造整个 Jacobian。

Hessian 是二阶偏导矩阵，描述曲率。Hessian 的特征值告诉我们每个方向是凸的还是凹的、曲率多大。牛顿法用 Hessian 的逆来调整步长，收敛快，但计算和存储成本高，深度学习中很少直接用。

## 梯度下降与学习率

最简单的优化方法是梯度下降：

```text
x ← x - η ∇f(x)
```

其中 `η` 是学习率。学习率太大会震荡甚至发散，太小会收敛很慢。对于凸函数，适当的学习率可以保证收敛；对于非凸的深度网络，学习率更多是靠经验和调度策略来调。

一个常见误解是「梯度为 0 就是最小值」。在高维空间里，梯度为 0 的点可能是局部极小、局部极大，也可能是鞍点。鞍点在某些方向上升、某些方向下降，深度网络里比局部极小更常见。这也是动量类方法有用的原因之一：它们能帮助越过鞍点和小平台。

## 约束优化与拉格朗日乘子

有时候我们不仅要最小化损失，还要满足约束，比如「权重范数不能超过某个值」。这类问题可以写成：

```text
min f(x)  s.t.  g(x) = 0
```

拉格朗日乘子法把约束吸收进目标：

```text
L(x, λ) = f(x) + λ g(x)
```

对 `x` 和 `λ` 求偏导并令其为 0，就得到最优性条件。直觉上，在约束边界上，目标函数的梯度和约束函数的梯度必须平行，否则还可以沿着边界继续改善。

深度学习中，L2 正则可以看作对权重大小的软约束，对抗训练可以看作对输入扰动的约束。理解约束优化的直觉，有助于理解这些技巧为什么有效。

## 最小二乘：一个能解出来的例子

线性最小二乘要最小化：

```text
||Ax - b||²
```

对 `x` 求导并令其为 0，得到正规方程：

```text
AᵀA x = Aᵀb
```

如果 `AᵀA` 可逆，解是 `(AᵀA)⁻¹Aᵀb`。这个闭式解在统计和线性回归里很重要，也说明了「最小化平方误差」的几何意义：把 `b` 投影到 `A` 的列空间上，残差和列空间正交。

深度学习一般不用闭式解，因为参数量太大、模型非线性。但最小二乘提供了理解损失函数和梯度的起点。

## 小结

- 浮点数有范围，指数和对数运算要做数值稳定处理。
- log-sum-exp 和取对数是最常用的防上溢/下溢技巧。
- 条件数衡量问题对扰动的敏感度，病态问题会让优化变难。
- 梯度给方向，Hessian 给曲率；深度网络通常只用一阶信息。
- 约束优化和最小二乘提供了理解正则化与损失函数的几何直觉。
