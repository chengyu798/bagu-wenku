## 高维数据背后的低维结构

一张人脸图像可能有上百万个像素，但真正变化的有意义因素并不多：身份、姿态、光照、表情。高维观测往往由少数潜在因素驱动。线性因子模型把这个直觉写成数学：观测 `x` 由低维潜在变量 `h` 经过线性变换加噪声生成。

这一章介绍的模型——因子分析、PCA、ICA、稀疏编码——都是这个思路的不同变体。它们是自编码器和深度生成模型的思想前身。

## 因子分析

因子分析假设：

```text
h ~ N(0, I)
x = W h + b + ε
ε ~ N(0, Ψ)
```

`h` 是低维潜在因子，`W` 是载荷矩阵，`ε` 是噪声，`Ψ` 通常假设为对角矩阵（各维噪声独立）。给定 `h`，`x` 的分布是高斯；边缘化 `h` 后，`x` 也是高斯，协方差是 `WWᵀ + Ψ`。

因子分析想回答的是：观测之间的相关性，能不能用少数潜在因子解释？如果能，`W` 的列就对应这些因子的方向。

## PCA 的概率视角

PCA 通常被介绍成一种降维算法：找方差最大的方向。它也可以看作因子分析的一个特例：当噪声各向同性且趋于 0 时，因子分析退化为 PCA。

PCA 的步骤是：

1. 中心化数据；
2. 计算协方差矩阵；
3. 对协方差矩阵做特征分解；
4. 取最大的几个特征值对应的特征向量；
5. 把数据投影到这些方向。

PCA 的优点是简单、有闭式解、可解释。缺点是只能捕捉线性结构，对非线性流形无能为力；而且它最大化的方差不一定和任务相关。

## 独立成分分析

PCA 找到的是不相关（正交）的方向，但不相关不等于独立。ICA 的目标是找到统计独立的潜在源。

经典场景是「鸡尾酒会问题」：多个麦克风同时录到多个人说话，ICA 试图把混合信号分离成独立的说话人。它假设源信号非高斯、相互独立，通过最大化非高斯性或最大化似然来估计混合矩阵的逆。

ICA 和 PCA 的区别在于目标：PCA 关心方差和去相关，ICA 关心独立性和源分离。如果数据本来就是高斯的，ICA 无法唯一确定源，因为高斯分布旋转后仍然高斯。

## 稀疏编码

稀疏编码假设观测可以由一组基向量的稀疏组合表示：

```text
x ≈ Σ h_i w_i
```

并且大多数 `h_i` 为 0。它通常使用过完备字典（基向量数量大于输入维度），并加稀疏惩罚：

```text
L = ||x - Wh||² + λ ||h||₁
```

稀疏编码的直觉是：自然图像可以用少量「边缘」「纹理」基元组合出来。学到的基向量往往像视觉皮层的感受野，具有局部性和方向选择性。

## 慢特征分析

慢特征分析（slow feature analysis）假设时间上变化缓慢的特征更有意义。它学习一组表示，使得表示随时间的变化尽量小，同时保持一定的方差，避免所有输出都变成常数。

这个思想在视频、语音、时序数据里很有用：快速变化的细节可能是噪声，缓慢变化的因素往往对应真正的状态。

## 这些模型的意义

线性因子模型的表达力有限，但它们提供了几个重要的概念：

- **潜在变量**：观测背后有低维原因。
- **生成过程**：先采样潜在变量，再生成观测。
- **表示学习**：好的表示应该抓住数据的变化因素。
- **概率建模**：用分布和似然来描述不确定性。

这些概念后来被自编码器、VAE、GAN 等深度模型继承和扩展。

## 小结

- 线性因子模型假设高维观测由低维潜在因子线性生成。
- 因子分析用高斯潜在变量和对角噪声建模观测。
- PCA 找方差最大的正交方向，可以看作因子分析的特例。
- ICA 追求统计独立，稀疏编码追求稀疏表示，慢特征分析追求时间上的缓慢变化。
- 这些模型是深度生成模型和表示学习的思想起点。
