## 生成模型要解决什么

判别模型学 `p(y|x)`，生成模型学 `p(x)`：数据本身是怎么产生的？学到之后，可以采样新样本、做密度估计、填补缺失、做半监督学习。

生成模型难在两点：高维分布的建模，以及归一化的计算。不同的生成模型，本质上是在「似然是否精确」「采样是否容易」「训练是否稳定」之间做不同取舍。

## 能量模型与玻尔兹曼机

能量模型用一个能量函数定义未归一化概率：

```text
p(x) = exp(-E(x)) / Z
```

能量低表示概率高。玻尔兹曼机是带隐变量的能量模型，可见层和隐藏层之间有连接。受限玻尔兹曼机（RBM）去掉了层内连接，使给定一层时另一层条件独立，Gibbs 采样很方便。

RBM 可以用对比散度训练，曾经是深度信念网络（DBN）的积木。DBN 先逐层无监督预训练，再整体微调，在深度网络训练困难的年代很有影响力。

## 深度玻尔兹曼机

深度玻尔兹曼机（DBM）堆叠多层隐藏层，表达力更强，但推断和训练都更难。它没有明确的层次生成方向，训练通常需要复杂的近似推断。

这类模型在理论上很重要，但在实践中逐渐被有向生成模型和后来的扩散模型取代。

## 变分自编码器

VAE 用变分推断训练：

```text
编码器：x → q(h|x)
解码器：h → p(x|h)
损失：重构误差 + KL(q(h|x) || p(h))
```

编码器输出潜在分布的均值和方差，训练时从该分布采样 `h`，再解码。为了让采样可反向传播，使用重参数化技巧：

```text
h = μ + σ ⊙ ε,  ε ~ N(0, I)
```

VAE 的优点是训练稳定、有显式似然下界、潜在空间连续。缺点是样本可能偏模糊，因为重构误差（如 MSE）倾向于平均多个可能的结果。

## 生成对抗网络

GAN 用一个生成器 `G` 和一个判别器 `D` 对抗训练：

```text
min_G max_D E[log D(x)] + E[log(1 - D(G(z)))]
```

生成器把噪声映射成样本，判别器区分真实样本和生成样本。训练目标是让生成样本骗过判别器。

GAN 的优点是样本锐利、采样快；缺点是训练不稳定、容易模式坍塌（只生成少数模式）、缺乏显式似然。后续的 WGAN、StyleGAN、条件 GAN 等做了大量改进。

## 自回归生成模型

自回归模型把联合分布分解成条件概率的乘积：

```text
p(x) = Π_i p(x_i | x_<i)
```

逐项生成，每一项都基于前面的内容。它似然精确、训练稳定，但采样是串行的，速度慢。PixelRNN、WaveNet、GPT 系列都属于这一类。

## 生成模型的评估

评估生成模型很难，因为没有单一指标能同时衡量似然、样本质量和多样性。

- **对数似然**：衡量密度估计，但对高维数据不一定和感知质量一致。
- **Inception Score**：衡量样本清晰度和多样性，但对某些数据集有偏。
- **FID**：比较真实和生成分布在特征空间的距离，常用但有偏差。
- **人工评估**：最可靠但成本高。

一个好模型应该同时做到：样本真实、覆盖所有模式、对训练分布不过拟合。

## 2016 年之后的演进

这一章写于 2016 年，之后生成模型发生了巨大变化：

- **扩散模型**：通过逐步去噪学习数据分布，在图像、视频、音频生成上成为主流。
- **流匹配 / 归一化流**：用可逆变换建模分布，似然精确、采样快。
- **大规模自回归 Transformer**：在文本、代码、多模态生成上占据主导。
- **多模态生成**：文本、图像、音频统一建模。

但核心问题没有变：如何表示高维分布、如何稳定训练、如何评估生成质量。VAE 的隐变量、GAN 的对抗、自回归的分解，仍然是理解新模型的基础。

## 小结

- 生成模型学习 `p(x)`，可用于采样、密度估计和半监督学习。
- 能量模型用未归一化概率，RBM 用 Gibbs 和 CD 训练。
- VAE 用变分推断，损失是重构项加 KL。
- GAN 用对抗训练，样本锐利但训练不稳定。
- 自回归模型似然精确，采样串行。
- 评估生成模型要同时看似然、样本质量和多样性。
