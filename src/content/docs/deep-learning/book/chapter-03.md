## 为什么深度学习要用概率

模型永远不可能完全确定。给一张模糊的图片，它可能 70% 像猫、30% 像狗；给一句话，下一个词有很多合理选择；训练数据本身也有噪声。概率提供了一套语言，把这些不确定性写清楚，并且告诉我们怎样在不确定性下做最优决策。

这一章分成两块：前半部分讲怎样描述随机性和做贝叶斯推断，后半部分讲信息论——熵、KL 散度和交叉熵。后者直接对应我们最常用的分类损失。

## 随机变量与分布

随机变量是一个取值不确定的量。离散随机变量用概率质量函数描述，比如掷骰子：

```text
P(X = 1) = P(X = 2) = ... = P(X = 6) = 1/6
```

连续随机变量用概率密度函数描述。密度本身不是概率，密度在区间上的积分才是概率。高斯分布是最常见的连续分布：

```text
p(x) = (1 / sqrt(2πσ²)) exp(-(x - μ)² / (2σ²))
```

它由均值 `μ` 和方差 `σ²` 决定，形状是钟形曲线。很多自然现象近似服从高斯分布，中心极限定理也解释了为什么大量独立因素叠加后会趋近高斯。

机器学习里还常用伯努利分布（二分类）、类别分布（多分类）、均匀分布和指数分布。选择什么分布，本质上是在对数据做假设。

## 条件概率与贝叶斯规则

条件概率 `P(y|x)` 表示在已知 `x` 的情况下 `y` 的概率。联合概率、条件概率和边缘概率之间的关系是：

```text
P(x, y) = P(y|x) P(x)
P(y|x) = P(x|y) P(y) / P(x)
```

第二条就是贝叶斯规则。它把「先验」`P(y)`、 「似然」`P(x|y)` 和「后验」`P(y|x)` 联系起来。

举一个医学检测的例子。某种病在人群中的患病率是 1%，检测的灵敏度是 99%（有病的人 99% 检出），特异度是 95%（没病的人 95% 判为阴性）。如果一个人检测阳性，他真正患病的概率是多少？

很多人会直觉认为是 99%，但用贝叶斯算一下：

```text
P(病|阳) = P(阳|病)P(病) / [P(阳|病)P(病) + P(阳|无病)P(无病)]
        = 0.99×0.01 / [0.99×0.01 + 0.05×0.99]
        ≈ 0.167
```

只有约 16.7%。原因是有病的人太少，假阳性虽然比例不高，但基数大。这个例子说明：**后验不仅取决于似然，还取决于先验**。很多「模型看起来很准」的问题，背后都是基准率在起作用。

## 期望、方差与常见分布

期望是随机变量的平均水平：

```text
E[X] = Σ x P(x)        # 离散
E[X] = ∫ x p(x) dx     # 连续
```

方差衡量偏离均值的程度：

```text
Var(X) = E[(X - E[X])²]
```

协方差描述两个变量是否一起变化。协方差矩阵在 PCA 里出现过，也是理解高斯分布和多变量建模的基础。

常见分布里，伯努利分布描述一次二选一试验，类别分布描述多选一，高斯分布描述连续噪声，指数分布常用来建模等待时间。深度学习里，输出层的选择往往对应一个分布假设：二分类用伯努利，多分类用类别分布，回归用高斯。

## 信息论：熵、KL 与交叉熵

熵衡量一个分布的不确定性：

```text
H(X) = -Σ P(x) log P(x)
```

如果一件事只有一种可能，熵是 0；如果所有结果等可能，熵最大。熵也可以理解为「平均惊异程度」或「编码这个分布所需的最短平均码长」。

KL 散度衡量两个分布的差异：

```text
D_KL(P || Q) = Σ P(x) log(P(x) / Q(x))
```

它不是距离，因为不对称：`D_KL(P||Q)` 和 `D_KL(Q||P)` 一般不相等。但它有一个重要性质：恒为非负，当且仅当两个分布相同时为 0。所以它可以用来衡量「用 Q 近似 P 的代价」。

交叉熵是：

```text
H(P, Q) = -Σ P(x) log Q(x)
```

它和熵、KL 的关系是：

```text
H(P, Q) = H(P) + D_KL(P || Q)
```

在分类任务里，真实标签 `P` 是 one-hot 分布，`H(P)` 是常数，所以最小化交叉熵等价于最小化 KL 散度，也就是让预测分布接近真实分布。

## 最大似然与交叉熵

假设我们有独立同分布的样本 `x₁, ..., xₙ`，模型参数为 `θ`。最大似然估计要最大化：

```text
Σ log p(xᵢ | θ)
```

也就是最小化负对数似然。对于分类问题，如果模型输出的是类别概率，负对数似然就是交叉熵。所以「最大似然」「最小化交叉熵」「最小化 KL」在分类场景下是同一件事的不同说法。

这个联系很重要：它解释了为什么交叉熵是分类的标准损失，也解释了为什么生成模型常用对数似然来训练。

## 小结

- 概率是对不确定性的建模语言，先验和似然共同决定后验。
- 贝叶斯规则提醒我们关注基准率，不要只看检测的准确率。
- 熵衡量不确定性，KL 衡量分布差异，交叉熵是分类损失。
- 最小化交叉熵等价于最小化预测分布和真实分布的 KL。
- 最大似然、负对数似然和交叉熵在分类问题里是相通的。
