## 图像任务的特殊性

一张 256×256 的彩色图像有约 20 万个输入。如果第一层全连接到 1000 个隐藏单元，参数量就是 2 亿。更糟的是，全连接层把每个像素位置都当成独立特征，完全忽略了图像的局部结构：相邻像素高度相关，物体出现在图像左侧还是右侧，语义是一样的。

卷积网络利用三个先验：**局部连接、参数共享、平移等变**。这三条假设大幅减少了参数，也让模型更容易从少量数据中学到有用的特征。

## 卷积在做什么

卷积核是一个小窗口，比如 3×3，里面有可学习的权重。它从图像左上角开始，按步幅滑动，每到一个位置就和窗口内的像素做加权求和，得到一个输出值。

```text
输出[i, j] = Σ_m Σ_n 输入[i·s + m, j·s + n] · 核[m, n]
```

如果核是

```text
[[ 1,  0, -1],
 [ 1,  0, -1],
 [ 1,  0, -1]]
```

它就会对水平方向的亮度变化敏感，起到边缘检测的作用。卷积核的权重不是人设计的，而是通过训练学出来的。网络可以自己发现「什么样的局部模式对任务有用」。

输出尺寸由输入尺寸、核大小、填充和步幅决定：

```text
输出尺寸 = (输入尺寸 + 2×padding - 核大小) / stride + 1
```

填充（padding）控制边界信息是否保留，步幅（stride）控制下采样程度。

## 参数共享与平移等变

同一个卷积核在整张图上滑动，所有位置共享同一组权重。这意味着：

- 参数量只和核大小、通道数有关，和图像大小无关；
- 猫的耳朵出现在左上角还是右下角，都用同一个探测器；
- 学到的特征具有平移等变性：输入平移，输出也跟着平移。

这不是「模型更聪明」，而是我们**把图像的先验写进了结构**。先验对了，模型需要的参数和数据就少。

## 池化

池化对局部区域做聚合，常见的是最大池化和平均池化。最大池化取窗口内的最大值，平均池化取平均值。

池化有三个作用：降低分辨率、减少计算量、扩大感受野。它还能提供一定的平移不变性：只要特征在窗口内移动，最大值可能不变。

但池化会丢失空间信息。对分类任务，这种丢失通常可以接受；对分割、检测、生成任务，过度池化会损害定位精度，所以现代架构常用步幅卷积或空洞卷积替代池化。

## 多通道与 1×1 卷积

实际输入有多个通道（RGB 三通道，中间层有几十到几千个通道）。一个卷积核的维度是「核高 × 核宽 × 输入通道数」，输出通道数由卷积核的数量决定。

1×1 卷积不混合空间位置，只在通道维度做线性组合。它计算便宜，常用来升降通道数、增加非线性、做跨通道信息整合。很多现代结构（ResNet 的瓶颈、Inception、Transformer 的 FFN 前身）都用到它。

空洞卷积（dilated convolution）在核元素之间插入空洞，不增加参数就能扩大感受野，常用于分割和音频。

转置卷积（transposed convolution）是卷积的「反向」操作，用于上采样，常见于分割和生成模型。它不是简单的插值，而是有可学习参数的。

## 经典结构的演进

- **LeNet**：早期的手写数字识别网络，卷积 + 池化 + 全连接。
- **AlexNet**：2012 年 ImageNet 突破，使用 ReLU、dropout、数据增强和 GPU 训练。
- **VGG**：用重复的 3×3 卷积堆深，结构简单规整。
- **ResNet**：引入残差连接，让梯度可以直接跳过层，训练非常深的网络成为可能。
- **Inception**：多尺度并行卷积，增加宽度和感受野的多样性。
- **DenseNet**：层与层之间密集连接，特征复用。

这些结构的共同趋势是：更深的网络、更好的梯度流动、更高效的计算。残差连接尤其重要，它后来也被 Transformer 广泛采用。

## 小结

- 卷积利用局部连接和参数共享，大幅减少参数。
- 卷积核是学出来的局部特征探测器；感受野随层数增大。
- 池化降低分辨率、扩大感受野，但会丢失空间信息。
- 1×1 卷积做通道混合，空洞卷积扩大感受野，转置卷积做上采样。
- 经典架构的演进围绕「更深、更好训练、更高效」展开。
