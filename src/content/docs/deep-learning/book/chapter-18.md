## 未归一化概率模型的训练难题

很多概率模型只定义未归一化的能量函数 `p̃(x)`，真实概率是：

```text
p(x) = p̃(x) / Z
```

`Z` 是对所有状态的求和或积分。配分函数难算，导致最大似然训练也难：对数似然的梯度里包含对模型分布的期望，而这个期望需要知道 `p(x)`。

这一章介绍几类方法：用 MCMC 估计梯度、用对比散度近似、用伪似然或 score matching 绕开配分函数、直接估计 `Z`。

## 对数似然梯度的结构

对参数 `θ`，对数似然的梯度可以写成：

```text
∇_θ log p(x) = ∇_θ log p̃(x) - E_{p(x)}[∇_θ log p̃(x)]
```

第一项是「正相」：提高真实数据样本的概率。第二项是「负相」：降低模型当前认为高概率的样本的概率。两项平衡，模型才会把概率质量放到数据分布上，而不是所有地方都高。

问题在于第二项需要对模型分布求期望。如果模型分布容易采样，就可以用样本估计；但很多模型恰恰难以采样。

## 随机最大似然

随机最大似然（stochastic maximum likelihood, SML）维护一条持续运行的 MCMC 链，用链上的样本作为负样本：

1. 从数据中取正样本；
2. 从持续 MCMC 链中取负样本；
3. 用正负样本估计梯度，更新参数；
4. 用更新后的参数继续跑链。

持续链的好处是负样本越来越接近当前模型分布。缺点是训练不稳定，链可能混合不好，参数更新又会改变目标分布。

## 对比散度

对比散度（contrastive divergence, CD）简化了负样本的获取：从数据样本出发，只跑少量 MCMC 步，用得到的样本近似负样本。

```text
正样本：x ~ data
负样本：x' ~ MCMC_k(x)
梯度：∇ log p̃(x) - ∇ log p̃(x')
```

`k` 通常很小（比如 1 步）。CD 的偏差来自「短链还没收敛到模型分布」，但它计算便宜，在 RBM 训练里非常常用。

CD 的直觉是：从真实数据出发，稍微往模型分布的方向走几步，用这个「被模型拉偏的样本」告诉模型「不要把这些也当成高概率」。它像一个局部的对比学习。

## 伪似然

伪似然绕开配分函数，用条件概率的乘积替代联合概率：

```text
p(x) ≈ Π_i p(x_i | x_{-i})
```

每个条件概率是 `p̃(x) / Σ_{x_i} p̃(x)`，归一化只在单个变量上进行，计算量小得多。伪似然不需要采样，训练稳定，但目标函数和真实似然不一致，尤其在变量强相关时偏差较大。

## Score matching

Score matching 不建模概率本身，而是匹配对数密度的梯度：

```text
s(x) = ∇_x log p(x)
```

这个梯度不需要知道 `Z`，因为 `Z` 对 `x` 的导数是 0。Score matching 直接最小化模型 score 和数据 score 的差异，后来在扩散模型中大放异彩。它把「学分布」转化为「学分数场」，是生成模型的重要思想。

## 估计配分函数

如果只关心 `Z` 的数值，可以用：

- **退火重要性采样**：在不同温度之间桥接，估计 `Z` 的比值；
- **桥式采样**：构造从已知分布到目标分布的路径；
- **AIS**：结合重要性采样和退火，是估计配分函数的常用方法。

这些方法通常计算量大，更多用于评估和理论研究，而不是日常训练。

## RBM 的例子

受限玻尔兹曼机（RBM）是可见层和隐藏层的二分图，层内没有连接。给定可见层，隐藏层条件独立；给定隐藏层，可见层条件独立。所以 Gibbs 采样很方便。

RBM 的训练常用 CD：从数据出发，采样隐藏层，再重建可见层，用原始数据和重建数据的差异更新权重。它曾经是深度信念网络的积木，后来被其他生成模型取代，但 CD 的思想仍然有教学价值。

## 小结

- 含配分函数的模型，最大似然梯度包含正相和负相。
- 负相需要对模型分布采样，MCMC 混合不好会导致偏差。
- SML 用持续链，CD 用短链近似，伪似然和 score matching 绕开配分函数。
- 配分函数本身可以用 AIS 等方法估计。
- score matching 是后来扩散模型的核心工具之一。
