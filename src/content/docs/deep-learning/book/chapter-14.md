## 没有标签，怎么学表示

自编码器的想法很朴素：让网络把输入压缩成一个表示，再从这个表示重建输入。如果重建得好，说明表示保留了输入的主要信息；如果表示维度更低，网络就被迫丢掉不重要的细节，留下有用的结构。

它由两部分组成：

```text
h = f(x)        # 编码器
x̂ = g(h)        # 解码器
L = ||x - x̂||²  # 重构损失
```

训练目标是最小化重构误差。整个过程不需要标签，所以属于无监督学习。

## 为什么需要瓶颈或正则化

如果编码器和解码器都足够强，网络可能直接学会恒等映射：`g(f(x)) = x`，表示没有任何压缩或抽象。为了防止这种情况，需要限制模型：

- **欠完备（undercomplete）**：让 `h` 的维度小于 `x`，形成瓶颈。
- **正则化**：在损失里加稀疏、收缩、噪声等约束。
- **去噪**：破坏输入，让模型恢复原始输入。

瓶颈迫使模型保留最重要的信息，而不是简单复制。

## 去噪自编码器

去噪自编码器（denoising autoencoder）先对输入加噪声或做遮挡：

```text
x̃ = x + noise
L = ||x - g(f(x̃))||²
```

模型看到的是损坏的输入，目标是恢复干净输入。它不能简单记住输入，必须学习数据中的稳定结构，才能把噪声去掉。这让表示更鲁棒，也更接近「理解」而不是「记忆」。

去噪自编码器在图像去噪、缺失值填补、特征学习中都有应用。

## 稀疏自编码器

稀疏自编码器在损失里加一个稀疏惩罚，让隐藏层中只有少量单元活跃：

```text
L = ||x - x̂||² + λ Σ |h_i|
```

稀疏性让表示更局部、更可解释，也更接近「少数原因解释观测」的假设。它可以用 L1 惩罚，也可以用 KL 散度约束平均激活接近一个很小的目标值。

## 收缩自编码器

收缩自编码器（contractive autoencoder）惩罚表示对输入的敏感度：

```text
L = ||x - x̂||² + λ ||∂f(x)/∂x||²
```

它希望输入小幅扰动时，表示不要剧烈变化。这让表示在数据流形上更平滑，对噪声更鲁棒。和去噪自编码器相比，收缩惩罚是解析的，不需要采样噪声，但计算 Jacobian 的代价更高。

## 预测型自编码器

预测型自编码器不是重建整个输入，而是用一部分输入预测另一部分。比如用中心像素预测周围像素，或用前面的词预测后面的词。它把「表示学习」和「预测任务」结合起来，学到的表示往往对下游任务更有用。

## 自编码器的应用

- **降维**：用瓶颈层做非线性降维，比 PCA 更灵活。
- **预训练**：早期用无监督预训练初始化深层网络，后来被更好的初始化和大量数据取代。
- **异常检测**：正常样本重构误差小，异常样本重构误差大。
- **去噪**：学习从损坏输入恢复干净输入。
- **生成模型的基础**：VAE 可以看作带概率解释的自编码器。

## 自编码器与 VAE 的区别

普通自编码器学的是一个确定性的编码函数，潜在空间可能不连续，随便采样一个点解码可能得到无意义的结果。VAE 让编码器输出一个分布，并对潜在分布加先验约束，使潜在空间更连续、更适合采样生成。

## 小结

- 自编码器用重构任务学习无监督表示。
- 瓶颈和正则化防止模型退化成恒等映射。
- 去噪、稀疏、收缩是三种常见的正则化方式。
- 自编码器可用于降维、预训练、异常检测和去噪。
- VAE 在自编码器基础上引入概率分布，使生成成为可能。
