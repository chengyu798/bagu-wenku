## 正则化到底在解决什么

训练一个深度网络时，训练误差通常会一直下降，但验证误差可能先降后升。后者上升的部分，就是模型开始记住训练集里的噪声和偶然模式。正则化的目标不是让训练误差更低，而是让**泛化误差**更低。

这一章介绍的正则化手段看起来五花八门，但背后的逻辑可以归成几类：限制参数大小、增加有效数据、增加噪声、限制模型自由度、组合多个模型。

## 参数范数惩罚

最直接的做法是在损失里加一项惩罚参数大小：

```text
L = L₀ + λ Ω(w)
```

**L2 正则**（权重衰减）令 `Ω(w) = ||w||²/2`。它会让权重整体变小，模型更平滑。梯度里多了一项 `λw`，所以每次更新都会把权重往 0 拉一点。

**L1 正则**令 `Ω(w) = ||w||₁`。它的梯度是常数符号项，容易把不重要的权重推到正好为 0，产生稀疏解。如果你想要特征选择或稀疏表示，L1 更合适。

L2 和 L1 都可以从贝叶斯角度解释：L2 对应高斯先验，L1 对应拉普拉斯先验。正则化强度 `λ` 控制先验的强弱，需要在验证集上调。

## 数据增强

如果模型看到的变化不够多，它就容易把偶然模式当成规律。数据增强通过对训练样本做保持标签的变换，人为扩大数据分布。

图像里常见的有翻转、裁剪、旋转、颜色抖动、Mixup、CutMix；语音里可以加噪声、变速、变调；文本里可以回译、同义替换、随机删除。增强的关键是**变换不能改变标签**，而且要覆盖真实世界可能出现的变化。

数据增强不只是「多造点数据」，它还把领域知识（比如「翻转后的猫还是猫」）作为归纳偏置注入模型，往往比单纯加正则化更有效。

## 噪声注入

给输入、权重或激活加噪声，也是一种正则化。输入加噪声迫使模型对小幅扰动保持稳定；权重加噪声可以看作对参数做随机扰动，类似集成；dropout 可以看作对激活加乘性噪声。

去噪自编码器就是噪声注入的典型应用：输入加噪，目标是恢复干净输入，模型因此学到更鲁棒的结构，而不是记住噪声。

## 早停

早停是最简单也最常用的正则化之一：在验证集上监控性能，验证误差不再改善就停止训练。

它的效果类似权重衰减：训练越久，参数越远离初始点，模型越贴合训练集。早停把「训练多少步」变成了一个正则化超参数。实践里通常保存验证集上最好的模型，而不是最后一轮的模型。

## 集成与 Dropout

**集成**是训练多个模型，预测时平均。不同模型的错误不完全相关，平均后方差降低，泛化提升。缺点是训练和推理成本成倍增加。

**Dropout** 在训练时以概率 `p` 随机把神经元输出置 0，推理时用全部神经元并对输出做缩放（或用 inverted dropout 在训练时缩放）。它可以理解为训练了指数多个共享参数的子网络，推理时做近似集成。

Dropout 迫使网络不能依赖某个特定神经元，表示更冗余、更鲁棒。它在全连接层效果明显，在卷积层要谨慎使用；现代架构里常用 BatchNorm、数据增强和其他正则化替代。

## 多任务、半监督与对抗训练

**多任务学习**让多个任务共享底层表示。共享部分被迫学习对多个任务都有用的特征，相当于一种归纳偏置，也能增加有效数据量。

**半监督学习**同时利用有标签和无标签数据。无标签数据可以帮助模型学习数据分布或表示，常见做法是自训练、一致性正则、伪标签。

**对抗训练**在输入上加入人眼不可见但能让模型出错的扰动，再让模型在这些扰动上训练。它能提升鲁棒性，但计算成本高，而且对某些类型的攻击仍然脆弱。

## 实践中的选择

- 先加数据增强和早停，这两项通常收益最大、实现最简单。
- 再过拟合明显时加权重衰减或 dropout。
- 数据很少时考虑迁移学习、半监督或更强的增强。
- 正则化强度不要拍脑袋，和验证集一起调。
- 不要同时把所有正则化拉满，否则模型会欠拟合，训练也会变慢。

## 小结

- 正则化优化的是泛化误差，不是训练误差。
- L1/L2 限制参数，数据增强扩大有效数据，噪声和 dropout 增加鲁棒性，早停限制训练时长，集成降低方差。
- 不同正则化手段可以组合，但要通过验证集控制强度。
- 正则化本质上是引入归纳偏置：告诉模型「什么样的解更可能正确」。
