## 机器学习的核心问题

机器学习要解决的不是「把训练集拟合得多好」，而是「在没见过的数据上表现多好」。这两件事经常不一致：一个模型可以把训练集背得滚瓜烂熟，换一批数据就完全失效。这一章围绕这个矛盾，讲清楚容量、过拟合、偏差方差、最大似然和正则化。

## 学习任务的形式化

监督学习假设数据来自某个未知分布 `p_data`，我们有一组带标签的样本 `(xᵢ, yᵢ)`。模型是一个参数化函数 `f_θ`，损失函数 `L` 衡量预测和真实标签的差距。训练目标是让经验风险最小：

```text
(1/n) Σ L(f_θ(xᵢ), yᵢ)
```

但真正关心的是期望风险：

```text
E_{(x,y)~p_data}[L(f_θ(x), y)]
```

经验风险只是期望风险的一个估计。样本越少，估计越不稳定，越容易过拟合。这就是为什么数据量、模型容量和正则化要一起考虑。

无监督学习没有标签，目标是学习数据结构、分布或表示。强化学习通过与环境交互获得奖励，学习策略。三者的共同点是：都在从有限经验中泛化。

## 训练集、验证集与测试集

实践中最常见的错误之一，是用测试集调超参数。正确做法是分三份：

- **训练集**：用来更新模型参数。
- **验证集**：用来选模型、调超参数、做早停。
- **测试集**：只在最后评估一次，反映真实泛化能力。

如果反复在测试集上试错，测试集就变成了验证集，你得到的「好成绩」不再可信。数据量小时，可以用交叉验证，把数据轮换着做验证。

## 容量、过拟合与欠拟合

容量指模型能拟合的函数复杂度。容量太低，模型连训练集都学不好，叫欠拟合；容量太高，模型把训练集的噪声也记住了，叫过拟合。

一个经典例子是多项式回归。用一次多项式拟合一组弯曲的数据，会欠拟合；用十次多项式，训练误差可能接近 0，但在两端剧烈震荡，测试误差很大。模型容量要和数据量、噪声水平匹配。

控制容量的方法有很多：减少参数、加正则化、加噪声、早停、集成。它们本质上都在限制模型「记住训练集」的能力。

## 偏差—方差分解

泛化误差可以分解成三部分：

```text
泛化误差 = 偏差² + 方差 + 不可约噪声
```

偏差来自模型假设太强，比如用线性模型拟合非线性数据；方差来自模型对训练数据扰动太敏感，比如高次多项式。偏差大表现为欠拟合，方差大表现为过拟合。

这两者通常此消彼长。增加容量会降低偏差、提高方差；增加数据或正则化会降低方差，但可能提高偏差。实践中的目标不是把某一项做到最小，而是让总和最小。

一个有用的直觉是：**模型越复杂，越容易受训练集抽样影响**。如果你换一批训练数据，模型输出变化很大，说明方差高；如果无论怎么换数据，模型都偏离真实规律，说明偏差高。

## 最大似然、MAP 与贝叶斯

最大似然估计（MLE）选择让观测数据概率最大的参数：

```text
θ_MLE = argmax Σ log p(xᵢ | θ)
```

它不包含任何先验偏好。最大后验（MAP）在似然上乘一个先验：

```text
θ_MAP = argmax [Σ log p(xᵢ | θ) + log p(θ)]
```

如果先验是高斯分布，`log p(θ)` 等价于 L2 正则；如果先验是拉普拉斯分布，等价于 L1 正则。所以「加正则」和「加先验」在数学上是同一件事。

贝叶斯方法更进一步：不只取一个点估计，而是保留参数的后验分布。它能表达不确定性，但计算成本更高，深度学习中通常用近似推断。

## 正则化的直觉

正则化是任何限制模型复杂度、提升泛化的手段。它不一定写在损失函数里：数据增强、早停、dropout、集成、参数共享，都是正则化。

为什么正则化能提升泛化？一种解释是它引入了归纳偏置：我们告诉模型「更简单的解更可能正确」。另一种解释是它限制了模型对训练集噪声的敏感度，降低了方差。

但正则化不是免费的。它引入偏差，可能让训练误差变高；强度太大时甚至会欠拟合。所以正则化系数要和验证集一起调。

## 小结

- 机器学习的目标是泛化，不是训练误差。
- 训练集、验证集、测试集各有职责，不能混用。
- 容量要和数据量匹配；欠拟合和过拟合是两种失败模式。
- 泛化误差可以拆成偏差、方差和噪声，复杂度和数据量在两者之间权衡。
- MLE、MAP、正则化在数学上紧密相关；正则化本质上是引入先验或限制复杂度。
