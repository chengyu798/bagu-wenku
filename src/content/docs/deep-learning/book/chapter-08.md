## 深度网络的优化为什么难

如果损失函数是凸的，梯度下降可以稳定地找到全局最优。但深度网络的损失是非凸的，参数维度极高，还存在病态曲率、鞍点、平台和悬崖。优化器要做的，不只是「沿梯度走」，还要在这样复杂的地形里保持稳定和效率。

这一章先讲困难在哪，再讲各类优化算法分别解决了什么问题。

## 非凸优化的几种地形

- **局部极小**：邻域内最小的点，但不一定是全局最优。高维空间里，真正的局部极小反而没有想象中多。
- **鞍点**：梯度为 0，但某些方向上升、某些方向下降。高维空间里鞍点比局部极小更常见，模型容易卡在这里。
- **平台（plateau）**：大片区域梯度很小，训练看起来停滞。
- **悬崖（cliff）**：梯度突然变得很大，一步更新可能把参数甩到很远。
- **病态曲率**：不同方向曲率差异很大，陡峭方向震荡、平坦方向走不动。

这些问题解释了为什么需要动量、自适应学习率、梯度裁剪和归一化。

## 随机梯度下降

标准梯度下降每次用全部数据算梯度，成本太高。随机梯度下降（SGD）每次用一个 mini-batch 估计梯度：

```text
θ ← θ - η · (1/B) Σ ∇L(θ; xᵢ)
```

mini-batch 的梯度是全集梯度的有噪估计。噪声不全是坏事：它帮助模型跳出尖锐的局部结构，也带来正则化效果。批量太小，噪声大、训练不稳；批量太大，显存吃紧、泛化未必更好。

学习率是最重要的超参数。太大震荡发散，太小收敛慢。常见做法是 warmup + 衰减，先小后大再逐渐减小。

## 动量

SGD 在峡谷形地形里会来回震荡。动量累积历史梯度：

```text
v ← βv + ∇L
θ ← θ - ηv
```

直觉上，它像一个小球在损失曲面上滚动：方向一致的梯度会加速，来回震荡的分量会互相抵消。`β` 通常取 0.9 左右。

Nesterov 动量先按当前动量走一步，再在那个位置算梯度，相当于「向前看」，收敛通常更快。

## 自适应学习率

不同参数的梯度尺度可能差很多。自适应方法根据历史梯度调整每个参数的学习率。

**AdaGrad** 累积梯度平方，频繁更新的参数学习率变小：

```text
s ← s + g²
θ ← θ - η g / sqrt(s + ε)
```

它适合稀疏特征，但累积会一直增大，学习率最终变得太小。

**RMSProp** 用指数移动平均代替累积，避免学习率衰减到 0。

**Adam** 同时估计梯度的一阶矩和二阶矩，并做偏差修正：

```text
m ← β₁m + (1-β₁)g
v ← β₂v + (1-β₂)g²
θ ← θ - η · m̂ / (sqrt(v̂) + ε)
```

Adam 收敛快、对超参数不敏感，是很多任务的默认选择。但在某些视觉任务上，调好的 SGD + 动量泛化可能更好。AdamW 把权重衰减和梯度更新解耦，是现代 Transformer 训练的常用变体。

## 二阶方法

牛顿法用 Hessian 的逆调整步长：

```text
θ ← θ - H⁻¹ ∇L
```

它在曲率大的方向走小步、曲率小的方向走大步，收敛快。但 Hessian 是 `n×n`，参数量上百万时无法存储和求逆。拟牛顿法（如 L-BFGS）用低秩近似，适合小规模问题，深度学习中不常用。

深度学习的二阶信息更多以「近似」的形式出现：BatchNorm 改变曲率、K-FAC 近似 Fisher 信息、自然梯度等。

## 批归一化

批归一化（BatchNorm）对每一层的输入做标准化：

```text
x̂ = (x - μ_batch) / sqrt(σ²_batch + ε)
y = γx̂ + β
```

`γ` 和 `β` 是可学习的缩放和偏移。它稳定了每层输入的分布，允许更大的学习率，加速训练，也有轻微正则化效果。

BatchNorm 的副作用是训练和推理行为不同：训练用当前 batch 的统计量，推理用移动平均。批量很小时统计量不稳定，可以改用 LayerNorm、GroupNorm 等。

## 训练技巧

- **梯度裁剪**：限制梯度范数，防止悬崖导致的爆炸，RNN 和 Transformer 常用。
- **学习率调度**：warmup、余弦衰减、阶梯衰减。
- **权重衰减**：和优化器配合，控制过拟合。
- **监控**：损失、梯度范数、参数更新比例、验证指标。
- **早停**：验证指标不再改善就停。

## 小结

- 深度优化的困难主要来自非凸、高维、病态曲率和鞍点。
- SGD 用 mini-batch 估计梯度，噪声有正则化作用。
- 动量减少震荡，自适应方法给不同参数不同步长。
- 二阶方法理论好但成本高，深度学习中多用一阶近似。
- BatchNorm、梯度裁剪和调度是稳定训练的重要工具。
