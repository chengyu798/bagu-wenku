## 一句话答案

进程是操作系统进行资源分配和保护的基本单位，拥有独立的虚拟地址空间；线程是 CPU 调度的基本单位，同一进程内的多个线程共享代码段、数据段和打开的文件，但各自有独立的栈、寄存器和程序计数器。

## 展开

| 维度 | 进程 | 线程 |
| --- | --- | --- |
| 资源 | 独立地址空间、文件描述符表 | 共享进程资源 |
| 切换开销 | 大（页表、TLB、上下文） | 小（寄存器、栈） |
| 通信 | IPC：管道、消息队列、共享内存、socket | 直接读写共享内存 |
| 隔离性 | 强，一个进程崩溃不影响其他进程 | 弱，一个线程崩溃可能拖垮整个进程 |

## 追问链

1. **线程切换为什么比进程快？** 同一进程内的线程共享页表，切换时不用更换地址空间，TLB 不必失效，主要保存和恢复寄存器与栈指针。
2. **协程和线程的区别？** 协程是用户态调度，切换不经过内核，开销更小；但一个协程阻塞会阻塞它所在的线程，除非配合异步 I/O。
3. **多进程和多线程怎么选？** CPU 密集型且需要隔离用多进程（例如 Python 用 multiprocessing 绕过 GIL）；I/O 密集型、需要共享状态用多线程或协程。

## 易错点

- 「线程是轻量级进程」只是类比，关键区别在资源分配与调度单位的不同。
- 线程共享堆，但不共享栈；每个线程有自己的栈。
